# DES (new.my.msd.govt.nz) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cover MSD's jobs site DES (search, job detail, locations, matches, profile, applications, apply, CV, sign-in) from the existing mymsd-mcp server, natively, with the same dry-run and self-repairing-session rules as the MyMSD part.

**Architecture:** A `DesHttp` transport (fetch for the JSON API with the SPA's headers; `node:https` for the sign-in navigations, which refuse fetch's `Sec-Fetch-Mode: cors`), a `repairDes` OAuth replay through B2C's SSO cookie, a `DesSession` owned by the existing `Session` (same jar, same `session.json`), and one tool module `src/tools/des.ts` with nine `des_*` tools and pure helpers.

**Tech Stack:** TypeScript (ES2023/NodeNext), @modelcontextprotocol/sdk, zod 4, node:test, node 24 (`/opt/homebrew/opt/node@24/bin/node`; `npm test` = build + all tests).

**Spec:** `docs/superpowers/specs/2026-10-12-des-design.md` (facts and endpoint shapes: `NATIVE-NOTES.md` §11).

## Global Constraints

- Node ≥ 22.13; no new runtime dependencies (zod + the MCP SDK only; `node:https` is built in).
- Every write tool takes `confirm` and is a dry run unless `confirm: true`; the dry run shows method, path, body and the effect in plain words, and sends nothing.
- Tool names are prefixed `des_`; results are `result(summaryLines, data)` from `src/format.ts`.
- Sign-in errors name the DES actions (`des_auth login` / `des_auth import_chrome`), never only MyMSD's.
- Never call `/bin/auth/logout` (it ends B2C's session too).
- Tests are offline: `globalThis.fetch` is replaced by a scripted stub and the navigation transport is injected.
- Work on branch `des`; one commit per task; `npm test` green at every commit.

## Review Focus

1. A Chrome import after a DES logout finds the cookie names with empty values: `des_auth import_chrome` must say there is no DES sign-in, and `addCookies` must drop empties — Task 3 (addCookies test) and Task 6 (import check).
2. `des_job` / `des_search` when DES cookies exist but the session and the SSO are both dead: the public endpoint must still answer — Task 6 tool test "des_job falls back to the public endpoint".
3. A cached `authenticated: true` must not be trusted past what `remaining` promised — Task 3 test "memo honours remaining".
4. `des_apply` without `confirm` must send no POST and must mask the csrf token in the shown request — Task 6 tool test.
5. Vacancy ids and search text with characters special to URLs/JSON must be encoded, not interpolated — Task 1 test (params via `searchParams.set`), Task 6 (apply request path uses `encodeURIComponent`).

```ts
import { randomUUID } from "node:crypto";
import https from "node:https";
import { NotLoggedInError, USER_AGENT } from "./http.js";
import type { CookieJar } from "./jar.js";
import { DES_ORIGIN } from "./paths.js";

/** DES answered with its envelope's error, or an HTTP status it does not explain. */
export class DesError extends Error {
  constructor(
    public code: string,
    message: string,
    public status: number,
    public data: unknown = null,
  ) {
    super(message);
  }
}

export interface NavResponse {
  status: number;
  headers: Record<string, string>;
  setCookie: string[];
  body: string;
}
/** A navigation-style request: GET, or POST of a urlencoded form when `form` is given. */
export type Navigate = (url: string, headers: Record<string, string>, form?: string) => Promise<NavResponse>;

/** node:https, because fetch() always adds `Sec-Fetch-Mode: cors` and DES's sign-in servlets refuse that with 403. */
export const httpsNavigate: Navigate = (url, headers, form) =>
  new Promise((resolve, reject) => {
    const u = new URL(url);
    const h: Record<string, string> = { ...headers };
    if (form !== undefined) {
      h["content-type"] = "application/x-www-form-urlencoded";
      h["content-length"] = String(Buffer.byteLength(form));
    }
    const req = https.request({ host: u.hostname, port: u.port || 443, path: `${u.pathname}${u.search}`, method: form === undefined ? "GET" : "POST", headers: h }, (res) => {
      const chunks: Buffer[] = [];
      res.on("data", (d: Buffer) => chunks.push(d));
      res.on("end", () => {
        const out: Record<string, string> = {};
        for (const [k, v] of Object.entries(res.headers)) if (k !== "set-cookie" && v !== undefined) out[k] = Array.isArray(v) ? v.join(", ") : v;
        resolve({ status: res.statusCode ?? 0, headers: out, setCookie: res.headers["set-cookie"] ?? [], body: Buffer.concat(chunks).toString("utf8") });
      });
    });
    req.on("error", reject);
    if (form !== undefined) req.write(form);
    req.end();
  });

const NAV_HEADERS = { accept: "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8", "accept-language": "en-NZ,en;q=0.9", "upgrade-insecure-requests": "1" };
type Params = Record<string, string | number | boolean | null | undefined>;

export class DesHttp {
  constructor(
    private readonly jar: CookieJar,
    private readonly onCookies: () => void = () => {},
    private readonly navigate: Navigate = httpsNavigate,
  ) {}

  /** The `__Host-csrf` cookie the SPA reads and passes as `?csrf=` on apply and renew. */
  csrfToken(): string | null {
    return this.jar.toJSON().find((c) => c.domain === "new.my.msd.govt.nz" && c.name === "__Host-csrf" && c.value !== "")?.value ?? null;
  }

  private store(url: string, set: string[]): void {
    if (set.length && this.jar.store(url, set)) this.onCookies();
  }

  private headers(extra: Record<string, string>, url: string): Record<string, string> {
    const h: Record<string, string> = { "user-agent": USER_AGENT, ...extra };
    const cookie = this.jar.header(url);
    if (cookie) h.cookie = cookie;
    return h;
  }

  /** A JSON API call like the SPA's: GET, or POST when a body is given; same-origin Referer because Sling's referrer filter wants it. */
  async api(path: string, body?: unknown, params: Params = {}): Promise<any> {
    const u = new URL(path, DES_ORIGIN);
    for (const [k, v] of Object.entries(params)) if (v !== undefined && v !== null && v !== "") u.searchParams.set(k, String(v));
    const url = u.toString();
    const headers = this.headers({ accept: "application/json", "content-type": "application/json", "x-transaction-id": randomUUID(), origin: DES_ORIGIN, referer: `${DES_ORIGIN}/en/jobs/` }, url);
    const res = await fetch(url, { method: body === undefined ? "GET" : "POST", headers, body: body === undefined ? undefined : JSON.stringify(body), redirect: "manual" });
    this.store(url, res.headers.getSetCookie());
    return this.parse(res);
  }

  /** Mirrors the SPA's response handling: 200 + JSON → the envelope; 401 or a redirect → no session; anything else → DesError with the site's message. */
  async parse(res: Response): Promise<any> {
    if (res.status >= 300 && res.status < 400) throw new NotLoggedInError(`DES redirected to ${res.headers.get("location") ?? "another page"}: no session`);
    const type = res.headers.get("content-type") ?? "";
    const text = await res.text();
    let json: any = null;
    if (type.includes("json") && text) {
      try {
        json = JSON.parse(text);
      } catch {
        json = null;
      }
    }
    if (res.status === 200 && json !== null) return json;
    if (res.status === 401) throw new NotLoggedInError("DES session has ended or was never started");
    const detail = json?.message ?? json?.error?.detail ?? (typeof json?.error === "string" ? json.error : null);
    const message = typeof detail === "string" && detail ? detail : text.replace(/<[^>]+>/g, " ").replace(/\s+/g, " ").trim().slice(0, 200) || `HTTP ${res.status}`;
    const code = json?.status ?? json?.statusCode;
    throw new DesError(code ? String(code) : `http_${res.status}`, message, res.status, json?.error ?? null);
  }

  /** A top-level navigation with the jar's cookies; redirects are left to the caller. */
  async nav(url: string, form?: string): Promise<NavResponse & { location: string | null }> {
    const r = await this.navigate(url, this.headers(NAV_HEADERS, url), form);
    this.store(url, r.setCookie);
    return { ...r, location: r.headers.location ?? null };
  }

  /** A binary download (the CV): the bytes, their type and the name the site suggests. */
  async fetchFile(path: string): Promise<{ bytes: Buffer; contentType: string; filename: string | null }> {
    const url = new URL(path, DES_ORIGIN).toString();
    const res = await fetch(url, { headers: this.headers({ accept: "*/*", referer: `${DES_ORIGIN}/en/jobs/` }, url), redirect: "manual" });
    this.store(url, res.headers.getSetCookie());
    const contentType = res.headers.get("content-type") ?? "";
    if (!res.ok || contentType.includes("text/html") || contentType.includes("json")) {
      await this.parse(res);
      throw new DesError("download_failed", `expected a file, got ${contentType || `HTTP ${res.status}`}`, res.status);
    }
    const raw = res.headers.get("content-disposition")?.match(/filename\*?=(?:UTF-8'')?"?([^";]+)"?/i)?.[1] ?? null;
    return { bytes: Buffer.from(await res.arrayBuffer()), contentType, filename: raw ? decodeURIComponent(raw) : null };
  }
}
```

```ts
import type { DesHttp } from "./des-http.js";
import { SsoDeadError } from "./http.js";
import { DES_ORIGIN } from "./paths.js";
import { parseAutoPostForm } from "./sso.js";

const HOP_HOSTS = ["new.my.msd.govt.nz", "identity.msd.govt.nz"];
const MAX_HOPS = 12;
/** where the sign-in lands: the signed-in "My jobs" page */
export const DES_RETURN = "/my-jobs/";
export const desLoginUrl = (): string => `${DES_ORIGIN}/bin/auth/login?rt=${encodeURIComponent(DES_RETURN)}`;

/**
 * Replays DES's OAuth sign-in natively: /bin/auth/login → B2C authorize (answered from B2C's SSO cookie) →
 * /bin/auth-redirect?code= (DES exchanges the code and sets its cookies) → the return page. A page that needs a
 * person, DES's own error page, a hop to a host we do not drive, a refusal or a loop is an SsoDeadError.
 */
export async function repairDes(http: DesHttp): Promise<void> {
  let url = desLoginUrl();
  let form: string | undefined;
  for (let hop = 0; hop < MAX_HOPS; hop++) {
    const u = new URL(url);
    if (!HOP_HOSTS.includes(u.hostname)) throw new SsoDeadError(`sign-in moved to ${u.hostname}, which needs a person`);
    const r = await http.nav(url, form);
    form = undefined;
    if (r.status >= 300 && r.status < 400 && r.location) {
      url = new URL(r.location, url).toString();
      if (/\/error\//.test(new URL(url).pathname)) throw new SsoDeadError(`DES rejected the sign-in (${url})`);
      continue;
    }
    if (r.status === 403) throw new SsoDeadError(`${u.pathname} refused the request (403 ${r.body.slice(0, 80).trim()})`);
    if (u.hostname === "identity.msd.govt.nz") {
      const f = parseAutoPostForm(r.body, url);
      if (f) {
        url = f.action;
        form = new URLSearchParams(f.fields).toString();
        continue;
      }
      throw new SsoDeadError("the identity provider wants a person (it showed its sign-in page)");
    }
    if (r.status === 200) return;
    throw new SsoDeadError(`unexpected HTTP ${r.status} from ${url}`);
  }
  throw new SsoDeadError("too many redirects during sign-in");
}
```

```ts
import { DesHttp, type Navigate } from "./des-http.js";
import { repairDes } from "./des-oauth.js";
import { NotLoggedInError, SsoDeadError } from "./http.js";
import type { Cookie, CookieJar } from "./jar.js";

const MEMO_MS = 60_000;
const DES_HOST = "new.my.msd.govt.nz";
export const DES_NEXT_STEP = "Sign in to DES: des_auth login, or sign in at new.my.msd.govt.nz in Chrome and run des_auth import_chrome.";

export interface DesInfo {
  authenticated: boolean;
  reason: string | null;
  remaining: number;
  renew: boolean;
  clientNumber: string;
  firstName: string;
  lastName: string;
  profileCompleteness: string;
  profileStatus: string;
  migratedUser: string;
}
export interface DesStored {
  info: DesInfo | null;
  checkedAt: number;
}

/** The DES half of the signed-in state: shares the jar with the MyMSD session, has its own check and repair. */
export class DesSession {
  readonly http: DesHttp;
  info: DesInfo | null;
  checkedAt: number;
  /** how many silent sign-ins this process has replayed */
  repairs = 0;
  private inflight: Promise<DesInfo> | null = null;

  constructor(
    readonly jar: CookieJar,
    private readonly save: () => void,
    stored?: DesStored,
    navigate?: Navigate,
  ) {
    this.http = new DesHttp(jar, save, navigate);
    this.info = stored?.info ?? null;
    this.checkedAt = stored?.checkedAt ?? 0;
  }

  toJSON(): DesStored {
    return { info: this.info, checkedAt: this.checkedAt };
  }

  /** a DES session cookie with a value (a logout leaves the names behind, empty) */
  hasCookies(): boolean {
    return this.jar.toJSON().some((c) => c.domain === DES_HOST && c.name.startsWith("__Host-") && c.value !== "");
  }

  /** B2C's SSO cookie, the one thing a silent sign-in needs */
  hasSso(): boolean {
    return this.jar.toJSON().some((c) => c.name.startsWith("x-ms-cpim-sso") && /identity\.msd\.govt\.nz$/.test(c.domain) && c.value !== "");
  }

  addCookies(cookies: Cookie[]): void {
    this.jar.add(cookies.filter((c) => c.value !== ""));
    this.checkedAt = 0;
    this.save();
  }

  forget(): void {
    this.jar.remove((c) => c.domain === DES_HOST);
    this.info = null;
    this.checkedAt = 0;
    this.save();
  }

  /** POST /bin/auth/check, the SPA's own probe: who is signed in and for how many more seconds. */
  async check(): Promise<DesInfo> {
    const s = (await this.http.api("/bin/auth/check", { type: "userInfo" })) ?? {};
    this.info = {
      authenticated: !!s.authenticated,
      reason: s.reason ?? null,
      remaining: Number(s.remaining ?? 0),
      renew: !!s.renew,
      clientNumber: s.clientNumber ?? "",
      firstName: s.firstName ?? "",
      lastName: s.lastName ?? "",
      profileCompleteness: s.profileCompleteness ?? "",
      profileStatus: s.profileStatus ?? "",
      migratedUser: s.migratedUser ?? "",
    };
    this.checkedAt = this.info.authenticated ? Date.now() : 0;
    this.save();
    return this.info;
  }

  /** A live DES session: a good check is trusted for 60 s and never past what `remaining` promised; concurrent callers share one repair. */
  async ensure(force = false): Promise<DesInfo> {
    const age = Date.now() - this.checkedAt;
    if (!force && this.info?.authenticated && age < MEMO_MS && age < (this.info.remaining - 30) * 1000) return this.info;
    if (!this.inflight) {
      this.inflight = this.establish().finally(() => {
        this.inflight = null;
      });
    }
    return this.inflight;
  }

  private async establish(): Promise<DesInfo> {
    let info: DesInfo | null = null;
    if (this.hasCookies()) {
      try {
        info = await this.check();
      } catch (e) {
        // a 401 or redirect from the check itself just means "no session": repair it like an authenticated: false
        if (!(e instanceof NotLoggedInError)) throw e;
      }
    }
    if (info?.authenticated) return info;
    if (!this.hasSso()) throw new NotLoggedInError(`No DES session. ${DES_NEXT_STEP}`);
    try {
      await repairDes(this.http);
    } catch (e) {
      if (e instanceof SsoDeadError) throw new NotLoggedInError(`DES session has ended and silent sign-in failed (${e.message}). ${DES_NEXT_STEP}`);
      throw e;
    }
    this.repairs++;
    info = await this.check();
    if (!info.authenticated) throw new NotLoggedInError(`DES still reports no session after single sign-on (${info.reason ?? "unknown reason"}). ${DES_NEXT_STEP}`);
    return info;
  }

  /** Runs `fn` against a live session; when the call reveals the session died, repairs once and retries once. */
  async run<T>(fn: (http: DesHttp) => Promise<T>): Promise<T> {
    await this.ensure();
    const before = this.repairs; // captured before the call: a repair another caller finishes meanwhile also counts
    try {
      return await fn(this.http);
    } catch (e) {
      if (!(e instanceof NotLoggedInError)) throw e;
      this.checkedAt = 0;
      await this.ensure(true);
      if (this.repairs === before) throw e; // the session was fine: the error is genuine
      return fn(this.http);
    }
  }

  status() {
    const left = this.info?.authenticated ? Math.max(0, Math.round(this.info.remaining - (Date.now() - this.checkedAt) / 1000)) : 0;
    return {
      signedIn: !!this.info?.authenticated,
      firstName: this.info?.firstName ?? null,
      clientNumber: this.info?.clientNumber ?? null,
      profileCompleteness: this.info?.profileCompleteness ?? null,
      profileStatus: this.info?.profileStatus ?? null,
      remainingSeconds: left,
      checkedAt: this.checkedAt ? new Date(this.checkedAt).toISOString() : null,
      repairsThisProcess: this.repairs,
      cookies: this.jar.names(DES_HOST),
      ssoCookie: this.hasSso(),
    };
  }
}
```

```ts
/** The SPA's search request and its limits (the search route's loader). */
export function searchBody(i: { query?: string; occupationGroups?: string[]; regions?: string[]; districts?: string[] }): Obj {
  const query = i.query?.trim() || undefined;
  const groups = (i.occupationGroups ?? []).map((g) => g.trim().toUpperCase()).filter(Boolean);
  for (const g of groups) if (!OCCUPATION_GROUPS[g]) throw new Error(`unknown occupation group ${g}; use ${Object.keys(OCCUPATION_GROUPS).join(", ")}`);
  const regions = (i.regions ?? []).map((s) => s.trim()).filter(Boolean);
  const districts = (i.districts ?? []).map((s) => s.trim()).filter(Boolean);
  if (!query && !groups.length && !regions.length && !districts.length) throw new Error("give a query, occupationGroups, regions or districts");
  if (query && query.length > 50) throw new Error("query is limited to 50 characters");
  if (regions.length + districts.length > 10) throw new Error("at most 10 regions and districts together");
  const filters: Obj = {};
  if (groups.length) filters.occupationGroups = groups;
  if (regions.length || districts.length) filters.locations = { ...(regions.length ? { regions } : {}), ...(districts.length ? { districts } : {}) };
  return { ...(query ? { searchTerms: query } : {}), filters };
}

  if (values(c.knowledge).length) lines.push(`Knowledge: ${values(c.knowledge).join(", ")}`);
  if (c.languageProficiencies?.length) {

    });
    lines.push(`Languages: ${langs.join("; ")}`);
  }
  if (values(v.credentials).length) lines.push(`Credentials: ${values(v.credentials).join(", ")}`);
  const sell = [v.sellingPoint1, v.sellingPoint2, v.sellingPoint3].filter(Boolean);
  if (sell.length) lines.push(`Highlights: ${sell.join(" | ")}`);
  if (v.vacancyPosting?.startDate) lines.push(`Posted ${day(v.vacancyPosting.startDate)}${v.vacancyPosting.endDate ? `, closes ${day(v.vacancyPosting.endDate)}` : ""}${v.vacancyPosting.postingType ? ` (${v.vacancyPosting.postingType})` : ""} ${jobUrl(v.vacancyId)}`);
  const a = r?.applicationForm;
  if (a) lines.push(`You applied: ${a.applicationFormName ?? a.applicationFormId} on ${day(a.submittedDateTime)}${a.applicationStage ? ` — ${a.applicationStage}` : ""}`);
  if (r?.client?.specialCautionToken) lines.push(`Special-caution flag on your record: ${r.client.specialCautionToken}${isBlocked(r.client.specialCautionToken) ? " (the site does not let you apply online)" : ""}`);

  if (desc) lines.push("", desc);

export const nzToday = (): string => new Date().toLocaleDateString("en-CA", { timeZone: "Pacific/Auckland" });

/** Why the site would not let this application start; empty when it would. */
export function applyChecks(detail: Obj, today = nzToday()): string[] {
  const v: Obj = detail?.vacancyDetails ?? {};
  const problems: string[] = [];
  const a = detail?.applicationForm;
  if (a) problems.push(`you already applied (${a.applicationFormName ?? a.applicationFormId}${a.applicationStage ? `, ${a.applicationStage}` : ""})`);
  if (v.vacancyStatus && v.vacancyStatus !== "Open") problems.push(`the job is ${v.vacancyStatus}`);
  if (v.vacancyPosting?.endDate && v.vacancyPosting.endDate < today) problems.push(`applications closed ${day(v.vacancyPosting.endDate)}`);
  if (isBlocked(detail?.client?.specialCautionToken)) problems.push(`your record carries a special-caution flag (${detail.client.specialCautionToken}); the site does not allow online applications — call 0800 779 009`);
  return problems;
}

export function summarizeApplications(r: Obj): string[] {
  const apps: Obj[] = r?.applications ?? [];
  const total = Number(r?.totalApplications ?? apps.length);
  if (!apps.length) return ["No job applications"];
  const lines = [`${total} job application${total === 1 ? "" : "s"}`];
  for (const a of apps) {
    const v = a.vacancy ?? {};
    const place = where(v.locations);
    lines.push(`  ${a.applicationFormName ?? a.applicationFormId}: ${v.vacancyTitle ?? "?"} (job ${v.vacancyId ?? "?"}) — ${a.applicationStage ?? "?"}${a.applicationStageReason ? ` (${a.applicationStageReason})` : ""}, applied ${day(a.submittedDateTime)}${place ? `, ${place}` : ""}`);
  }
  return lines;
}

export function summarizeProfile(client: Obj | undefined, jobseeker: Obj | undefined): string[] {
  const lines: string[] = [];
  const u1 = unavailable(client);
  if (u1) lines.push(`Client profile: ${u1}`);
  else {
    const p = client?.person ?? {};
    const j = client?.jobseeker ?? {};
    lines.push(`${[p.firstName, p.lastName].filter(Boolean).join(" ") || "Unknown name"} (client ${p.clientNumber || "?"}) — ${p.email || "no email"}, ${p.phone || "no phone"}`);
    const addr = [p.personOtherStreet, p.personOtherCity, p.personOtherPostalCode, p.personOtherCountry].filter(Boolean).join(", ");
    if (addr) lines.push(`Address: ${addr}`);
    lines.push(`Jobseeker: ${j.status ?? "status unknown"}, profile ${j.profileCompleteness ?? "unknown"}; job notifications by ${client?.preference?.employmentCommunicationPreference ?? "unknown"}`);
    if (p.specialCautionToken) lines.push(`Special-caution flag: ${p.specialCautionToken}${isBlocked(p.specialCautionToken) ? " (blocks online applications)" : ""}`);
  }
  const u2 = unavailable(jobseeker);
  if (u2) lines.push(`Jobseeker profile: ${u2}`);
  else if (jobseeker) {

    if (s.personal?.summary) lines.push(`Summary: ${s.personal.summary}`);
    const skills = values(s.workSkills, (x) => x.skill?.value);

    const other = values(s.otherSkills, (x) => x.skill?.value);
    if (other.length) lines.push(`Other skills: ${other.join(", ")}`);
    const strengths = values(s.strengths, (x) => x.skill?.value);
    if (strengths.length) lines.push(`Strengths: ${strengths.join(", ")}`);
    if (s.workExperiences?.length) {

    }
    if (s.educations?.length) lines.push(`Education: ${s.educations.map((e: Obj) => `${e.courseName?.value ?? "?"}${e.placeOfLearning ? ` (${e.placeOfLearning})` : ""}`).join("; ")}`);
    const langs = values(s.languageProficiencies, (l) => l.language?.value);
    if (langs.length) lines.push(`Languages: ${langs.join(", ")}`);
    const classes = values(s.driverlicence?.licencesClass, (c) => c.credential?.value);
    lines.push(`Driver licence: ${s.hasAnyNzdriversLicence ?? "unknown"}${classes.length ? ` (${classes.join(", ")})` : ""}; reliable transport: ${s.reliableTransportAvailable ?? "unknown"}`);
    const wants = values(s.jobsInterested, (x) => x.job?.value);
    if (wants.length) lines.push(`Jobs wanted: ${wants.join(", ")}`);
    const places = values(s.locationsInterested, (x) => x.location?.value);
    if (places.length) lines.push(`Locations wanted: ${places.join(", ")}`);

    if (w?.hoursOfWork || w?.daysAvailable) lines.push(`Availability: ${[w.hoursOfWork, w.daysAvailable, values(w.specificDays).join("/")].filter(Boolean).join("; ")}`);
    lines.push(`Edit the profile on the site: ${DES_ORIGIN}/en/forms/jsp (MSD's profile wizard)`);
  }
  return lines;
}

const LEVELS = ["island", "region", "district", "suburb"];
export function flattenLocations(results: Obj[] | undefined, depth = 0, out: string[] = []): string[] {
  for (const r of results ?? []) {
    out.push(`${"  ".repeat(depth)}${r.description} — ${LEVELS[depth] ?? "area"} (${r.code})`);
    if (r.children?.length) flattenLocations(r.children, depth + 1, out);
  }
  return out;
}
```

```ts
function registerAccountTools(server: McpServer, session: Session, { signedIn }: { open: (fn: (http: DesHttp) => Promise<ToolResult>) => Promise<ToolResult>; signedIn: (fn: (http: DesHttp) => Promise<ToolResult>) => Promise<ToolResult> }): void {
  const des = session.des;

  server.registerTool(
    "des_auth",
    {
      description:
        "Sign-in state and sign-in actions for DES (new.my.msd.govt.nz). status: who is signed in, how long the session has left, which cookies are held. " +
        "import_chrome: take the sign-in from Google Chrome's Default profile (be signed in at new.my.msd.govt.nz there). " +
        "login: open a browser window at the DES sign-in (the optional CloakBrowser when installed; otherwise your own browser, after which you run import_chrome). " +
        "forget: drop the DES cookies and state only. The session repairs itself through MSD's identity provider while its single-sign-on cookie lasts.",
      inputSchema: {
        action: z.enum(["status", "import_chrome", "login", "forget"]).default("status"),
        chromeProfile: z.string().optional().describe('Chrome profile folder, default "Default"'),
      },
    },
    async (args) => {
      try {
        switch (args.action) {
          case "status": {
            if (des.hasCookies() || des.hasSso()) await des.ensure().catch(() => {});
            return result([whoami(des), `Optional browser installed: ${await browserAvailable()}`], des.status());
          }
          case "import_chrome": {
            const cookies = (await readChromeCookies({ profile: args.chromeProfile, domains: DES_DOMAINS })).filter((c) => c.value !== "");
            if (!cookies.some((c) => c.domain === "new.my.msd.govt.nz" && c.name.startsWith("__Host-"))) {
              return desFail(new Error("Chrome holds no DES sign-in (its new.my.msd.govt.nz cookies are missing or empty). Sign in at new.my.msd.govt.nz in Chrome, then run this again."));
            }
            des.addCookies(cookies);
            const info = await des.ensure(true);
            return result([`Imported ${cookies.length} cookies from Chrome. ${whoami(des)}`], { imported: cookies.map((c) => `${c.domain} ${c.name}`), signedIn: info.authenticated });
          }
          case "login": {
            if (await browserAvailable()) {
              des.addCookies(await harvestCookies({ jar: session.jar, headless: false, waitForAuth: true, timeoutMs: 5 * 60_000, site: "des" }));
              await des.ensure(true);
              return result([`Signed in through the browser window. ${whoami(des)}`], des.status());
            }
            await openInChrome(harvestStart("des"));
            return result(["Opened the DES sign-in in your browser. Sign in there, then run des_auth import_chrome."], { browserInstalled: false });
          }
          case "forget": {
            des.forget();
            return result(["Forgot the DES session (the MyMSD and RealMe cookies are kept)."], des.status());
          }
        }
      } catch (e) {
        return desFail(e);
      }
    },
  );

  server.registerTool(
    "des_apply",
    {
      description:
        "Apply for a job on DES — the site's three-step flow in one call: which CV (existing = the CV MSD already holds; own = you email your CV back on the confirmation email), whether you have a referee, then submit. " +
        "Checks first that you have not applied, the job is Open and not closed, and nothing on your record blocks online applications. Dry run unless confirm: true.",
      inputSchema: {
        id: z.string().min(1).describe("the job's vacancy id"),
        cv: z.enum(["existing", "own"]).describe("existing: use the CV MSD already has; own: send your own CV by replying to the confirmation email"),
        reference: z.enum(["Yes", "No"]).describe("do you have someone who can be your reference"),
        confirm: z.boolean().default(false).describe("send it; without this the exact request is shown and nothing is sent"),
      },
    },
    async (args) =>
      signedIn(async (http) => {
        const detail = (await http.api("/bin/sep/vacancies/details", undefined, { vacancyId: args.id }))?.results ?? {};
        const title = detail.vacancyDetails?.vacancyTitle ?? args.id;
        const problems = applyChecks(detail);
        if (problems.length) return desFail(new Error(`cannot apply for ${title}: ${problems.join("; ")}`));
        const csrf = http.csrfToken();
        if (!csrf) return desFail(new NotLoggedInError(`DES has not given this session a __Host-csrf cookie. ${DES_NEXT_STEP}`));
        const request = applyRequest(args.id, args.cv, args.reference, csrf);
        const effect = `an application for "${title}" (job ${args.id}) will be submitted with ${args.cv === "existing" ? "the CV MSD already holds" : "your own CV, which you then email back on the confirmation email"} and reference: ${args.reference}`;
        if (!args.confirm) return dryRun({ method: "POST", path: request.path.replace(/csrf=.*/, "csrf=<__Host-csrf>"), body: request.body }, effect, { job: summarizeJob(detail).slice(0, 3) });
        const r = (await http.api(request.path, request.body))?.results ?? {};
        return result([`Applied for ${title}: application ${r.applicationFormName ?? "?"} (${r.applicationFormId ?? "?"}).${args.cv === "own" ? " Reply to MSD's confirmation email with your CV attached." : ""}`], r);
      }),
  );

  server.registerTool(
    "des_cv",
    {
      description: "Download the CV MSD holds for you from DES. Signed in.",
      inputSchema: { path: z.string().optional().describe("where to save it; default: the temp dir, named as the site names it") },
    },
    async (args) =>
      signedIn(async (http) => {
        const f = await http.fetchFile("/bin/bff/cv");
        const to = args.path ?? join(tmpdir(), f.filename ?? `mymsd-des-cv${extFor(f.contentType)}`);
        mkdirSync(dirname(to), { recursive: true });
        writeFileSync(to, f.bytes);
        return result([`Saved your CV (${f.bytes.length} bytes, ${f.contentType}) to ${to}`], { path: to, bytes: f.bytes.length, contentType: f.contentType, filename: f.filename });
      }),
  );
}
```
